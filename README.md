- **Platform**: macOS arm64 (Apple Silicon)
- **Size**: ~57.8MB
- **Type**: Mach-O 64-bit executable

## Installation
```bash
# Copy binary to your PATH
cp bird /usr/local/bin/bird
chmod +x /usr/local/bin/bird
```

## Usage
```bash
bird read https://x.com/user       # Read timeline
bird tweet "Hello world"            # Post tweet
bird dm list                        # Direct messages
bird --help                         # Full help
```
